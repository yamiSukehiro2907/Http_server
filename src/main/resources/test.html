❌ Error Handling Test Cases

404 Not Found

Requests a file that does not exist to trigger a 404 error.

405 Method Not Allowed

Uses an unsupported HTTP method (PUT) to trigger a 405 error.

405 Unsupported Method

Uses the DELETE method, which is not supported by the server.

415 Invalid Content-Type

Sends XML data to an endpoint expecting JSON to trigger a 415 error.

400 Malformed JSON

Sends a syntactically incorrect JSON string to trigger a 400 error.

415 Unsupported Media

Requests a `.pdf` file, a media type not configured on the server.

🔒 Security Test Cases

403 Deep Traversal (../../)

Attempts to traverse multiple levels up the directory tree.

403 Absolute Path

Attempts to use an absolute file path, which should be blocked.
